# Huggee-Farm
An interactive 3D farm (Three.js) where trending Hugging Face models live as Huggies.
Huggy art: Chunte/HFBA Space (Hugging Face brand assets, "free to use"). Avatars: Hugging-Farm, Monster-Code.
Run: `python3 -m http.server 8080` then open http://localhost:8080
